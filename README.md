# web-tech


## How to install:
1. clone the repository
2. in the route folder do: `npm install` (also install listed dependencies for the **backend**)
3. in the frontend folder do `npm install` (also install listed dependencies for the **frontend**)
4. run `npm run dev` in the root folder and also in the frontend folder. (We have 2 seperate Folders for frontend/backend)

## dependencies

### backend
- becryptjs
- express
- cors
### frontend
- axios
- react-router-dom
